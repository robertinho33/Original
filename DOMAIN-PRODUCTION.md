# DOMÍNIO DE PRODUÇÃO — AUREA

Domínio principal:

www.fiosperfeitos.com.br

Domínio raiz:

fiosperfeitos.com.br

## Configuração

No painel da Render:

Settings
→ Custom Domains
→ Add Custom Domain

Adicionar:

www.fiosperfeitos.com.br

Depois adicionar:

fiosperfeitos.com.br

## DNS

A Render fornecerá os registros DNS
exatos para o serviço criado.

Não inventar registros manualmente.

Copiar os valores apresentados pela
Render para o provedor DNS do domínio.

## HTTPS

A Render provisiona o certificado TLS
depois que o domínio estiver corretamente
apontado e validado.

O acesso final deve ser:

https://www.fiosperfeitos.com.br

## Canonical

O domínio público principal da loja será:

https://www.fiosperfeitos.com.br
