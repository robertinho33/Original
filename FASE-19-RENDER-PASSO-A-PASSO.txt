============================================================
AUREA — CRIAÇÃO DO WEB SERVICE NA RENDER
============================================================

1. Abra o painel da Render.

2. Entre em:

   Dashboard
   → New
   → Blueprint

3. Conecte sua conta GitHub.

4. Selecione:

   robertinho33/Original

5. Branch:

   main

6. A Render deve detectar:

   render.yaml

7. Confirme o serviço:

   aurea-cosmetics

8. Confirme:

   Runtime:
   Node

   Build:
   npm ci --omit=dev

   Start:
   npm start

   Health:
   /api/health

9. Configure o Secret:

   AUREA_ADMIN_TOKEN

   Use uma senha/token com pelo menos
   32 caracteres.

   NÃO coloque o valor no Git.

10. Confirme:

    CORS_ORIGINS

    https://www.fiosperfeitos.com.br,https://fiosperfeitos.com.br

11. Confirme o Persistent Disk:

    Name:
    aurea-data

    Mount Path:
    /app/server/data

    Size:
    10 GB

12. Crie o serviço.

============================================================
APÓS O PRIMEIRO DEPLOY
============================================================

A Render fornecerá uma URL temporária
do serviço.

Use essa URL para verificar:

/api/health

Depois:

/api/monitoring/readiness

E:

/api/monitoring/metrics

============================================================
DOMÍNIO
============================================================

No serviço:

Settings
→ Custom Domains

Adicionar:

www.fiosperfeitos.com.br

Adicionar também:

fiosperfeitos.com.br

A Render mostrará os registros DNS
necessários.

COPIE OS REGISTROS MOSTRADOS PELA RENDER.

Não invente valores DNS.

Depois que o DNS propagar:

HTTPS será validado pela Render.

URL pública:

https://www.fiosperfeitos.com.br
